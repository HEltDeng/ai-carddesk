# AI 代充站调研：渠道、收款、国内访问与开源搭建

核验日期：2026 年 10 月 22 日。研究范围：50 个零售/代充站点样本，另查聚合目录、兑换入口、7 个 GitHub 项目，以及 X 上的经营者公开信息。

**结论：现成商城和自动发卡体系已经有可用实现；可持续利润取决于供货、收款、获客和售后。海外服务器、便宜地区或一套 Session 兑换网页，单独都不能解决这些问题。**

这次已读到 50 个样本的原站商品或帮助说明，部分动态页面通过浏览器补核。没有实际下单、提交账号凭证、联系供应商、审计商家账目，也没有进行中国大陆三网测速。因此这是一份公开资料调研，不是“50 家经过交易验证的成熟供应商”名单。站点数量不等于独立主体或独立上游数量。所有商家报价、销量、官方渠道、质保及安全承诺均按公开自述记录。

## 1. 先回答你提出的几个问题

| 问题 | 当前结论 | 还缺什么 |
|---|---|---|
| 这类业务是不是非常赚钱 | 有价差、复购和代理分销，但同质化严重，部分零售价已接近公开批发价；没有净利润证据 | 真实采购、支付费率、获客、退款和封号损失数据 |
| 能不能放链动小铺，再去自己的站兑换 | 有公开实例：Aileader 关联了链动店铺、自有商城及独立兑换域名 | 对本人的主体、具体商品、外跳和履约方式取得平台准入确认 |
| 国内是不是一定不允许 | 不能一概而论；应分中国法律、平台准入、支付准入、模型厂商条款四层判断 | 具体经营主体、客户地区、商品性质、支付合同及必要法律意见 |
| 国外服务器国内能不能访问 | 通常可以，但不保证每地区、运营商、时段都可用；网站能访问也不等于 AI 服务可在相应地区使用 | 大陆移动/联通/电信对真实页面及支付回调的测试 |
| 菲律宾/智利是不是最低 | 存在地区定价，但没有证据支持所有产品、套餐和渠道都在这两地最低 | 同 SKU、同期限、同账号资格、同税费和汇率的结算报价 |
| 有无自动兑换源码 | 商城、发码、代理分销有开源；真实订阅支付能力通常依赖独立上游或私有服务 | 可签约供应商、接口文档、合法支付来源、退款责任 |

## 2. 现有网站实际上怎么赚钱、怎么交付

先区分六种商品：本人账号订阅、成品账号、共享席位、优惠资格商品、API/中转余额、代付服务。搜索结果中它们经常被放在一起，“最低价”很容易来自不同商品。试用、半价资格、短时体验、教育优惠不能默认当成可长期复购的正常月费。

[PriceAI](https://priceai.cc/channels) 更接近比价、报价聚合和导流入口，其说明不是交易销售或担保服务。大量报价可能来自同一个寄售平台或同一供货链，不能据报价数推导独立渠道数。它适合发现商家，再逐一返回原站查商品和条款；它不是供货授权证明。

这次找到与目标最接近的实例是 [Aileader 商城](https://aileaderme.top/)：页脚写着 Dujiao-Next，导航提供独立的卡密兑换入口，并链接 [链动小铺店铺](https://wzyp.cn/shop/Aileader)。同一经营者的 [X 账号](https://x.com/xing_eth) 也关联这些入口。链动店显示认证、保证金和销量徽标，属于平台展示信息，本次没有独立核实。

其业务结构可以拆成：

1. 链动小铺或自有商城展示商品、接单、收款。
2. 付款确认后从库存分配唯一 CDK，交给买家。
3. 买家在独立兑换页面使用 CDK，并按该商品要求提供必要信息。
4. 兑换服务向供货方建立充值任务，等待其返回结果。
5. 订单需要区分已支付、已发码、兑换处理中、已到账、失败待退等状态。

**CDK 通常是商家的库存/订单凭证，并不自动等于模型厂商发行的官方礼品卡。** OpenAI 当前确有美国限定、美元计价的官方礼品卡/钱包机制，所以也不能笼统说“完全没有官方礼品卡”；它与这些第三方 CDK 的发行方、适用地区及兑现责任不同。[OpenAI 多币种与钱包说明](https://help.openai.com/en/articles/10421635-multicurrency-billing)

“自动发货”也不一定等于“自动充值”。例如 AI订阅达人 的 Claude 人工服务同时显示自动交付标签；天策分自动/人工处理；GETGPT Plus 的 FAQ 描述人工服务时段。系统自动交给用户一个码或客服链接，只完成了交付的一步。[AI订阅达人](https://aikitmax.com/)、[天策AI](https://tiancexai.com/)、[GETGPT Plus FAQ](https://getgptplus.ai/faq)

供应商下一步至少需提供：可核验主体与合同、订阅/支付凭证样例、资金及卡片使用授权说明、适用地区及账号资格、未用码有效期、成功到账定义、失败超时与退回路径、掉订阅与封号责任、接口鉴权/签名/回调/重复请求规则、近30天可核实履约记录。先获得这些，再决定是否做实际测试单；不要先为最低档大量压款。

## 4. 支付：向客户收钱，与给上游付款，是两个问题

| 环节 | 可能路径 | 必须核实的条件 |
|---|---|---|
| 大陆客户付款 | 经批准的微信/支付宝商户收单，或合规平台交易 | 真实业务类目、主体、结算账户、费率、保证金、冻结/退款规则；聚合接口不会自动免除这些要求 |
| 海外客户付款 | 符合主体条件的 Stripe 等收单机构 | 收单地区、实体与银行账户、该业务是否获准、拒付和准备金；海外 VPS 不是海外商户资质 |
| 官方网页订阅支付 | 符合服务地区和账单条件的信用卡/借记卡，部分地区有本地方式 | 卡发行地区、真实持有人/授权、账单资料、账号地区、3DS、税费与续订规则 |
| iOS / Android 内购 | Apple App Store / Google Play 的适用支付方式 | 商店地区、商品、税费、资格与退款政策；不能直接套用网页价格 |
| 向批发商采购 CDK | 按合同购买与结算 | 批发商如何完成上游履约、失败是否原路退、有效期、是否会要求敏感凭证 |

OpenAI 官方确认网页有 PHP、CLP 等本币，应用商店订阅另由 Apple/Google 管理；菲律宾网页支持 GCash。该资料只证明支付方式和地区定价存在，没有证明“境外任何一张卡都能替任意地区用户充值”。[OpenAI 多币种说明](https://help.openai.com/en/articles/10421635-multicurrency-billing)

当日 Apple 官方商品列表中，菲律宾有 ChatGPT Plus ₱999、智利有 ChatGPT Plus CLP19,990 的内购条目。同列表有其他同名高价项，需在实际购买页确认期限；这组数据不能推导网页价、批发价或全网最低价，也没有按当日实时汇率换算。[菲律宾 App Store](https://apps.apple.com/ph/app/chatgpt/id6448311069)、[智利 App Store](https://apps.apple.com/cl/app/chatgpt/id6448311069)

所以，“用哪个地区的卡”应由真实主体、用户/账号适用地区、商品渠道及支付授权决定。可以向可核验的供应商采购合法适用的商品，但不应以伪造地址、冒用居民/学生资格或规避地区限制来构造利润。尚无材料证明你们目前具备菲律宾或智利的合格采购和收单条件。

Stripe 在其他国家开立商户账户的官方要求涉及当地实体、税号、地址、电话、身份材料、网站和符合条件的银行账户，具体例外按其规则处理。[Stripe 官方要求](https://support.stripe.com/questions/requirements-to-open-a-stripe-account-in-another-country?locale=en-GB)

## 5. 国内合规与“腾讯不允许”需要分开判断

**不能把“肯定违法”或“放国外就没事”任何一句作为经营依据。** 以下是资料核查和待确认事项，不代替针对实际主体、合同与经营方式的法律判断。

| 层面 | 查到的依据 | 对本项目的影响 |
|---|---|---|
| 网站接入/备案 | 腾讯云说明，大陆服务器对外开站通常须办理备案，香港等境外部署不适用同一大陆接入备案场景 | 地点影响接入手续，不自动豁免经营、税务、消费者权益、数据保护等义务 |
| 微信支付 | 官方运营规范要求合法合规经营，违反规则可停用支付权限 | “腾讯云能租”“微信能打开”“微信支付允许收款”是不同判断；不能以别家通道推定自己的准入 |
| 链动小铺 | 当前公开禁售目录列出 iTunes账号及充值、Apple ID相关服务、VPN及代理等类别 | 不能照搬别店所有SKU；AI原号代充、iOS履约、外跳兑换如何归类，需要平台针对具体方案确认 |
| 模型厂商地区与账号条款 | OpenAI 对不支持地区的访问/提供访问及不支持地区支付方式有明确限制 | 把网站部署在香港，不会改变最终用户地区或自动取得经销资格 |
| 生成式AI服务监管 | 暂行办法针对向境内公众提供生成内容的服务等规定适用范围 | 单纯商品交易与直接运营镜像聊天/API服务应分别分析，不应一起上线后才考虑 |
| 凭证和个人信息 | 涉及告知、最小必要、安全保障与跨境传输等要求 | 收取Session并传给第三方上游，增加数据责任；要明确收谁的什么信息、给谁、存多久 |

依据：[腾讯云备案场景](https://cloud.tencent.com/document/product/243/19630)、[微信支付运营规范](https://pay.wechatpay.cn/doc/v2/partner/4014115432)、[链动小铺禁售目录](https://wzyp.cn/article/alias/forbid-sale)、[OpenAI 不支持地区说明](https://help.openai.com/en/articles/9131992-chatgpt-and-api-services-in-unsupported-countries-and-territories)、[ChatGPT 支持地区清单](https://help.openai.com/en/articles/7947663-chatgpt-supported-countries)、[生成式人工智能服务管理暂行办法](https://www.cac.gov.cn/2023-07/13/c_1690898327029107.htm)、[个人信息保护法](https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm)。

中国大陆不在当前 ChatGPT 官方支持地区清单内，这是独立于服务器、支付和网站备案的产品条款约束。腾讯官方资料中，本次没有找到足以支持“腾讯一切产品一律禁止所有AI代充”这一笼统结论的条文；也没有找到对本项目的肯定准入。

链动小铺目录页面标注2023-04-07，当前仍作为官方禁售入口展示；日期旧并不能自行认定其失效。既有AI店铺只能证明商品在展示，不能代替具体业务许可。应提交准确商品和交付说明，询问书面准入；本次没有代为联系或申请。

## 6. Session 兑换为什么不能直接照抄

很多商家将“不需要密码”和“只需 Session”并列宣传。**Session、access token 或 sessionKey 可能具有账号访问能力，具体权限取决于凭证类型；它不是普通的收货地址。** 不输入密码并不等于没有授予访问能力，也没有证据支持“支付成功后凭证必然立刻失效”。[OpenAI 账号共享与安全说明](https://help.openai.com/en/articles/10471989-openai-account-sharing-policy)

商家声称只在本地解析账号标识、不留日志、充值后删除，属于可以检验的技术承诺，本次没有源代码/网络传输审计来验证。调查时没有把本人的或用户的任何凭证输入这些站。

如果开展技术原型，先实现商品、订单、付款沙箱、测试码、库存锁、任务状态和售后工单。真实账号接入应等数据边界与获授权的履约方式确定后再做。浏览器的登录令牌交给第三方，不应被包装为官方 OAuth 或官方充值 API；普通 OpenAI API 余额也不能直接当 ChatGPT Plus 月费余额使用。

## 7. 域名、Cloudflare 和服务器怎么选

可以把三件事分清：域名注册是买名字；DNS 是把名字指向服务；云服务器是运行商城、数据库和任务的机器。Cloudflare 还提供代理/CDN、防护与 Workers 等能力，但买域名或开免费 DNS 不会自动得到一台可运行任意 PHP/Go 程序的 VPS。

对这次候选系统，较直观的技术原型是：中性自有品牌域名 → Cloudflare DNS/按测试决定是否代理 → 香港、日本或新加坡的 VPS → Dujiao-Next + 数据库 + 任务服务。这里是架构建议，不是已经选定供应商或实测最优线路。

1. 域名按续费价、注册商政策和真实持有人资料选择；避免让名称暗示官方关系。Cloudflare Registrar 提供按成本注册/续费，但支持的后缀和最终金额要看结算。[Registrar](https://developers.cloudflare.com/registrar/)
2. 域名也可在其他注册商购买，再接入 Cloudflare DNS。在 Cloudflare Registrar 买的域名必须使用其 nameservers，不能直接改到其他DNS供应商，换供应商通常涉及转移注册商。[官方注册限制](https://developers.cloudflare.com/registrar/get-started/register-domain/)
3. 小规模原型可从2核、2–4GB内存的普通VPS评估，按实际依赖、队列与访问量调整。第一阶段应月付验证，不以低价长期预付替代线路测量。
4. 部署时设置独立管理员认证、HTTPS、数据库非公网访问、备份和恢复演练；支付回调/订单/兑换接口不应被缓存。公开站无需为了自动化暴露管理端口。
5. 必须在真实大陆网络测：域名解析、首页首屏、收银台加载、支付通知、订单查询、兑换状态；晚高峰和移动端也要覆盖。单台机器的 ping 不能代表所有用户体验。

**国外服务器通常可从国内访问，但免费 Cloudflare 不等于大陆 CDN。** Cloudflare China Network 需要 Enterprise、额外订阅、ICP备案/许可和内容审查，是另一套产品。不能把免费橙云当作大陆访问质量承诺。[China Network 开通要求](https://developers.cloudflare.com/china-network/get-started/)

未购买域名、VPS或付费CDN；没有当前可报价的指定域名，也没有大陆三网测试结果，因此本报告不承诺月费或延迟。

## 9. X 上的信息：有经营线索，没有利润审计

[Aileader经营者2026-10-21的帖文](https://x.com/xing_eth/status/2112819434079531038) 自称近期增加了代理和分站、日流水过万元，并描述两个自动化程序重复发货，以及代理子域名命名导致域名停用。这些数量和因果均是作者自述，没有账目或注册商材料核验。可借鉴的是单个订单只能兑现一次、人工补发后要同步状态、域名命名及权限要控制；不能据流水推算利润，也不能据“用几个Bot管理”跳过财务权限管理。

[LiuNeng 的 X 主页](https://x.com/LiuNengBoy) 与商店入口相互关联，可用于核验公开经营身份的一致性；不是供应资质证明。X搜索和经营者帖子适合发现近期变化，最终仍应回到原站条款、官方政策、合同和实测。

本次没有声称50家都在X有可验证运营记录。对50站的比较主要来自它们的原站公开页面；GitHub用于源码筛选，X用于经营线索交叉核验。

## 10. 接下来按这个顺序推进

**第一步，确定可售商品和交易责任。** 首批只研究一种清楚的本人账号月度订阅SKU；明确服务地区、商品来源、付款方、实际履约方、数据接收方、保障范围。先获得链动小铺与拟用收单机构对准确业务描述的准入答复。平台展示已有同类店铺不能代替这一步。

**第二步，把三个价格样本变成可比较报价。** 可从丁丁AI、Aileader、贝贝这几个有明码的入口询价取证，定位为调查对象，不是已批准供应商。统一询问同商品、同地区、同渠道、同账号状态、同保障、5/10/50件价格、未用码时效及退款条件。任何最低价都要带适用条件。

**第三步，做订单原型。** 优先Dujiao-Next，用模拟商品、测试支付和测试CDK演示商城/库存/兑换状态/退款，不需要先处理真实Session。链动平台若无获准的API，先研究平台发码到自有兑换页的简单形态；平台外跳自主收款是另一个模式，不能混淆收款与责任归属。

**第四步，限定规模做履约验证。** 在商品、平台、支付、用户资格及数据处理方式确定后，再由获授权人员用合法适用的测试账户试单；完整观察30天售后周期。记录成功率、人工耗时、到账时间、掉订阅、退款、投诉与实际毛利，期间不做年费预售或大额压货。

**第五步，再决定是否上线自有收款和代理系统。** 只有试点数据证明净贡献利润足以覆盖获客与售后、供货可追溯、退款可以执行，才扩大。先前的源码选型与域名知识足够支撑原型，但不足以证明商业模式已经闭环。

可用于平台咨询的准确问题是：“拟由本主体销售【具体AI产品/套餐】的【本人账号月度订阅服务或特定兑换码】，上游采用【真实履约方式】，用户在【店铺/自有域名】付款或兑换；是否准入、允许哪些外跳和凭证处理、需要何种资质、由谁承担退款、结算及投诉？”本次只准备了问题，没有发送信息、提交申请或接受协议。
